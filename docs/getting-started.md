# Getting Started

The first time you open FUNC, it asks you to choose a [password](/password) and then downloads the node software. When that's done, the dashboard shows a **Getting Started** checklist that walks you through four steps.

## 1. Start your node

Click **Set Up Node**. FUNC creates a background service that runs the node and starts it again whenever your computer restarts.

## 2. Sync with the network

The node downloads the network's latest state using fast catchup. This usually takes under an hour. Progress shows on the dashboard, but you don't have to watch it: you can close the page and the node keeps running.

## 3. Generate a participation key

Click **Generate Key...** and enter the address of the account you want to participate with. You don't need a wallet for this step. Generating the key takes a few minutes.

## 4. Register the key to go online

Connect the wallet that holds the account, then register the key. If you use a staking pool or escrow account, copy the key's details into its site instead. [Participating in Consensus](/consensus) has the details for both.

When your account is online, the checklist goes away and the dashboard's **Consensus** light turns green.

::: tip Just running a node?
If you don't plan to participate, click **Hide** on the checklist. Every option is still in the [Manage menu](/manage).
:::
