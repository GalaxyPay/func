# Keeping Your Node Running

- **Restarts:** the node starts again automatically when your computer restarts.
- **Sleep:** set your computer to **never sleep**, or the node stops while it's asleep. An offline node can't vote, even if your account is registered online.
- **Stopping:** if you stop the node and then restart your computer, the node starts again. To keep it from starting, use **Remove Service** in the [Manage menu](/manage). Removing the service keeps your node data; deleting the data is a separate step.
- **The dashboard:** the page doesn't need to be open for the node to run. It's more efficient to close it when you're not using it.
- **Updates:** a dot on the Settings gear means a new version of FUNC or the node is available. See [Settings](/settings).
